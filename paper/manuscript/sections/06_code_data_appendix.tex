
\section*{Code and Data Availability}

The Agent-MD source code, campaign and case specifications, authoritative archive manifest, figure-source data, plotting scripts, event schemas, Codex CLI reasoning-agent metadata and the GPT-5.5 model identifier, and frozen replay artifacts will be released through a versioned repository at \url{GITHUB-URL}. The repository version corresponding to this manuscript will be preserved as a tagged release. The repository will distinguish rule-based campaign-agent execution records from optional reasoning-agent records and will document the Codex CLI reasoning-agent interface and GPT-5.5 model identifier used in this study. Large trajectory and restart files are not included, but the machine-readable records and source data required to reproduce the workflow logic, tables, and figures are provided.

\appendix
\section{Repository and Reproducibility Artifacts}
\label{app:repo_artifacts}

This appendix summarizes the principal classes of machine-readable artifacts used to define, execute, audit, and reproduce the Agent-MD campaign. Exact filenames, repository paths, and file-level checksums will be provided in the versioned public repository. The artifact classes below distinguish approved campaign definitions, persistent operational records, authoritative scientific results, review evidence, and reproducible reporting inputs. Persistent operational records document campaign progression but do not by themselves establish final-result authority; the accepted-state manifest and final quality-control records define the authoritative result package, exclude stale, smoke, failed, or superseded outputs, and provide the accepted states from which figure-source data are derived.
