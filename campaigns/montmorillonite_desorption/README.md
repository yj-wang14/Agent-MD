# Montmorillonite desorption campaign

`campaign.yaml` defines the five-system RH 0.9 -> 0.3 -> 0.1 manuscript campaign. `cases/` contains only the five approved system definitions. The referenced ClayCode inputs, force-field files, and additional simulation templates are not included in this release candidate pending redistribution review; the illustrative SPC/E topology template is included. The unmodified historical definitions remain preserved in the private immutable baseline.
