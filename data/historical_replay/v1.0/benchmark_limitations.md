# Benchmark Limitations

This is a two-case retrospective blinded incident replay selected for authentic time-local evidence availability. No repeated trials, retry sampling, prompt tuning, evidence-bundle tuning, ground-truth tuning, scoring-rule tuning, or case-selection changes were performed after observing the clean two-case outcomes.

The sample is too small for claims of general diagnostic accuracy. The benchmark tests reasoning over state semantics and provenance from compact evidence bundles; it does not test automatic event detection, autonomous recovery, simulation execution, or broad production reliability.
