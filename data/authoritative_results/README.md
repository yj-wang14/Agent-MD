# Authoritative-result records

The original historical authority is preserved unmodified in the private immutable baseline. Files named `*.public.*` are privacy-safe public derivatives: environment-specific paths are replaced while scientific values, accepted-state identities, strict-pass status, RH values, system identifiers, timestep values, stored hashes, exclusion decisions, and provenance relationships are preserved. They must not be interpreted as original production paths.

Release-friendly CSV files under `../figure_source_data/` and `../table_source_data/` are derived from authoritative accepted states and reproduce the manuscript figures and tables. Operational state is retained separately and is not final-result authority.
